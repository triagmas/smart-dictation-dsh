# Smart Dictation для DeepSeek Harness

Локальная диктовка по-русски прямо в композере DSH: русская речь, английские технические термины
латиницей, пунктуация, личный словарь и обучение только после подтверждения. Аудио и текст не
покидают машину: облачные speech API не используются.

**Статус:** `1.0.0`, DSH Web, локальный GigaAM v3 E2E CTC INT8.

## Возможности

- Одна фиксированная кнопка микрофона 28×28 в композере. Она же останавливает запись; панель не
  раздвигается и не превращается в тулбар.
- Запись 16 кГц mono PCM16 WAV, ограничение 120 секунд, отмена по повторному клику или `Escape`.
- Распознавание на хосте через ONNX Runtime; модель скачивается один раз (~225 МБ) и проверяется по
  SHA-256. Повреждённый файл заменяется автоматически.
- Постобработка: убирает слова-заполнители, расставляет пунктуацию и капитализацию, исправляет
  английские термины по словарю.
- Стартовый словарь распространённых терминов (`Kubernetes`, `Docker`, `TypeScript`, `C++`,
  `C#`, `PR`, `CI`, `Codex`, `package.json` и другие). Его можно чистить, импортировать и
  экспортировать.
- Карточка «Запомнить …?» после подтверждённой правки в отправленном сообщении. Запись появляется
  только после **Да**; обучение отключается в настройках.
- Отдельный раздел **Настройки → Smart Dictation**, без кнопок внутри композера.
- Без автоотправки: распознанный текст всегда сначала попадает в редактируемый черновик.

## Установка

Нужны DSH `0.2.2-rc.1`–`0.2.x`, Node.js 22.19+, рабочий микрофон и ~400 МБ свободного места.

```bash
dsh plugin --profile web add https://github.com/triagmas/smart-dictation-dsh/releases/download/v1.0.0/smart-dictation-dsh-bundle-1.0.0.tgz
```

Перезапустите DSH и разрешите микрофон для адреса DSH Web. Первая диктовка сама подготовит модель;
отдельное нажатие «Подготовить модель» не требуется.

Не включайте одновременно экспериментальный официальный bundle Voice Input: оба регистрируют
сервис `speech-to-text` и будут конкурировать за провайдера.

## Использование

1. Нажмите микрофон в композере и говорите.
2. Нажмите ту же кнопку, чтобы остановить запись.
3. Проверьте вставленный текст и отправьте сообщение вручную.

«Текст редактируется» означает, что распознанная фраза вставляется в обычное поле ввода DSH как
черновик: до отправки её можно исправить, дописать или удалить. Пунктуация и термины исправляются
до вставки, а не после отправки.

Если после отправки DSH нашёл исправленный термин, появится карточка с вопросом. `Escape` или
**Нет** закрывают её без изменений. `Escape` во время записи отменяет текущую диктовку.

## Приватность

- Аудио живёт в памяти браузера только во время записи и уходит на локальный хост DSH.
- Транскрипты не логируются и не сохраняются отдельно; они вставляются в черновик.
- Словарь хранится в каталоге данных DSH; `localStorage` — только кэш для чтения.
- Сеть нужна для первой загрузки модели; распознавание полностью локальное.

## Разработка

```bash
pnpm install
pnpm typecheck
pnpm vitest run
pnpm --filter @smart-dictation/dsh-provider build
pnpm --filter @smart-dictation/dsh-client build
pnpm release:pack
pnpm release:verify
```

Пакеты:

| Пакет | Роль |
| --- | --- |
| `packages/smart-dictation-core` | Чистые функции: пунктуация, словарь, обучение, CTC |
| `packages/smart-dictation-provider` | ONNX Runtime, GigaAM, WAV, Typert-словарь |
| `packages/smart-dictation-client` | React-кнопка, запись, настройки, кэш |
| `packages/smart-dictation-bundle` | Cordis-patch и установочный bundle |

`pnpm release:pack` собирает три `.tgz` в `.release/artifacts/`; зависимости bundle указывают на
release-ассеты GitHub, поэтому установка не требует публикации в npm.

## Ограничения

- Русская речь с английскими терминами; длинные фразы полностью на английском пока не поддержаны.
- Нет wake word, потоковых субтитров и синтеза речи.
- Windows-приложение и другие оболочки вне DSH Web в эту версию не входят.
- Модель и `onnxruntime-node` занимают около 400 МБ после установки.
