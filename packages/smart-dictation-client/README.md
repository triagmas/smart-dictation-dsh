# @triagmas/dsh-smart-dictation-client

DSH Web client for Smart Dictation.

- One fixed 28×28 microphone control in `conversation.input.activity`.
- Records 16 kHz mono PCM16 WAV, shows level in the same icon, never auto-sends.
- Cleans filler words, applies the personal glossary, and inserts editable text.
- Offers a confirmation card after a term was corrected; the Host glossary is authoritative.
- Adds a dedicated Settings section with model preparation, glossary import/export and learning.
